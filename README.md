# ApexValue ChatGPT

Et første MVP-udkast af appen med:

- Web UI til at indtaste virksomhedens nøgletal.
- API endpoint (`POST /api/valuate`) til valuation-estimat.
- Enkel scoringsmodel for multiple + risikoniveau.

## Kør lokalt

```bash
npm start
```

Åbn derefter `http://localhost:3000`.

## Test

```bash
npm test
```
